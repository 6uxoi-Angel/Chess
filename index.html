Возможности

Спокойствие каждой клетки

Продуманные инструменты для игры, подготовки и анализа — без лишнего шума.

Игра двух игроков

Сразитесь за одной доской с другом. Ходы чередуются автоматически, подсветка доступных клеток помогает ориентироваться.

Игра против Stockfish

Выберите сторону — белые или чёрные. Движок автоматически отвечает за противника, рассчитывая лучшие ходы.

Подсветка ходов

Доступные клетки отмечены точками, взятия — кольцом. Последний ход, шах и варианты движка также подсвечиваются.

Анализ позиции

Оценка в пешках и три главных продолжения Stockfish. Стрелка первого хода лучшего варианта прямо на доске.

Редактор позиции

Добавляйте, удаляйте и перемещайте фигуры. Укажите сторону хода, проверьте корректность позиции перед игрой.

Импорт и экспорт FEN

Загрузите позицию из FEN или скопируйте текущую в буфер обмена. Поддержка файлов для дальнейшей работы.

История и отмена

Полная история ходов партии. Отмена последнего действия, превращение пешки и корректное отображение результата.

Отдельный поток движка

Stockfish запускается в отдельном рабочем потоке, сохраняя отзывчивость интерфейса во время расчётов.

Защита от устаревших данных

Если позиция изменилась во время анализа, результат для старой позиции игнорируется. Только актуальные данные.

Как пользоваться

Просто и поэтапно

Игра

  1. 01

    Нажмите на фигуру, затем на клетку назначения. Доступные клетки отмечаются точками или кольцом для взятия.

  2. 02

    Кнопка Игра: два игрока по очереди включает режимы вы белыми и вы чёрными. В этих режимах Stockfish отвечает за противоположную сторону.

  3. 03

    Нажмите Анализ позиции, чтобы получить оценку и три лучших варианта продолжения.

  4. 04

    Используйте Отменить ход, чтобы вернуться назад, или Новая партия, чтобы начать заново.

Горячие клавиши

Ctrl + Z отменить
F перевернуть
Esc закрыть

Редактор позиции

  1. 01

    Нажмите кнопку Игра, чтобы переключиться в режим Редактор.

  2. 02

    Выберите фигуру на панели и нажмите клетку доски, чтобы разместить её. Ластик или правая кнопка мыши удаляют фигуру.

  3. 03

    Без выбранной фигуры фигуры можно перетаскивать мышью по доске.

  4. 04

    Используйте Ход белых / Ход чёрных, чтобы указать сторону хода.

  5. 05

    Импорт FEN открывает ввод позиции — нажмите Enter, чтобы применить. Экспорт FEN копирует позицию в буфер и сохраняет в файл.

Перед переходом в режим игры редактор проверяет корректность позиции. Для партии нужны оба короля и соблюдение шахматных правил.

Как работает анализ

Stockfish в отдельном потоке

Приложение запускает движок в отдельном рабочем потоке, сохраняя отзывчивость интерфейса во время расчётов.

+0.32
Оценка позиции

Оценка с точки зрения белых. Положительное значение — преимущество белых, отрицательное — чёрных. Мат отображается в формате #N.

Главные варианты
1. e4 e5 2. Nf3 Nc6
2. d4 d5 3. exd5
3. Bc4 Bc5 3. c3

До трёх главных вариантов (principal variations) от движка.

Стрелка на доске

Первый ход лучшего варианта отображается стрелкой прямо на доске. Визуально понятно, какой ход предлагает движок.

Защита от устаревших результатов

Если положение изменилось во время анализа, результат для старой позиции игнорируется. Применяются только актуальные расчёты для текущей позиции.

Установка

Запуск за минуту

Быстрый запуск

Для Windows

1

Скачайте или клонируйте репозиторий.

2

Откройте папку проекта.

3

Запустите run.bat

Скрипт проверит зависимости и при необходимости установит версии из requirements.txt, затем откроет приложение.

Скачать приложение
Ручная установка

В PowerShell

PS C:\Chess> py -3.13 -m pip install -r requirements.txt
PS C:\Chess> py -3.13 app.py

Windows 10/11

Python 3.13 или новее с командой py

Процессор с поддержкой AVX2

Движок уже находится в папке stockfish. При необходимости укажите другой путь через переменную окружения STOCKFISH_PATH.

Проверка установки

После запуска в верхней части панели должна появиться зелёная надпись Stockfish готов. Если вместо неё отображается ошибка, проверьте, что stockfish/stockfish-windows-x86-64-avx2.exe существует и может быть запущен.
