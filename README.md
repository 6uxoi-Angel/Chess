# Шахматный анализатор

Desktop-приложение на Python и Pygame для игры в шахматы, подготовки позиций и анализа с помощью Stockfish.

![Аватар приложения](ava.jpg)

## Возможности

- Игра двух игроков за одной доской.
- Игра против Stockfish за белых или чёрных.
- Подсветка доступных ходов, последнего хода, шаха и варианта движка.
- Анализ позиции: оценка в пешках и три главных продолжения Stockfish.
- Редактор позиции: добавление, удаление и перемещение фигур.
- Импорт и экспорт FEN.
- История ходов, отмена последнего действия, превращение пешки и отображение результата партии.

## Требования

- Windows 10/11.
- Python 3.13 или новее с командой `py`.
- Процессор с поддержкой AVX2 для включённой в проект сборки Stockfish.

Движок уже находится в папке `stockfish`. При необходимости можно указать другой путь к Stockfish через переменную окружения `STOCKFISH_PATH`.

## Быстрый запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `run.bat`.

Скрипт проверит зависимости и при необходимости установит версии из `requirements.txt`, затем откроет приложение.

## Ручная установка

В PowerShell из корня проекта выполните:

```powershell
py -3.13 -m pip install -r requirements.txt
py -3.13 app.py
```

## Как пользоваться

### Игра

1. Нажмите на фигуру, затем на клетку назначения.
2. Доступные клетки отмечаются точками или кольцом для взятия.
3. Кнопка `Игра: два игрока` по очереди включает режимы `вы белыми` и `вы чёрными`. В этих режимах Stockfish автоматически отвечает за противоположную сторону.
4. Нажмите `Анализ позиции`, чтобы получить оценку и три лучших варианта.
5. Используйте `Отменить ход`, чтобы вернуться к предыдущему состоянию, или `Новая партия`, чтобы начать заново.

Клавиши:

- `Ctrl+Z` — отменить последнее действие.
- `F` — перевернуть доску.
- `Esc` — снять выделение фигуры или закрыть диалог.

### Редактор позиции

1. Нажмите кнопку `Игра`, чтобы переключиться в `Редактор`.
2. Выберите фигуру на панели и нажмите клетку доски, чтобы разместить её.
3. Выберите `Ластик` или нажмите правую кнопку мыши на фигуре, чтобы удалить её.
4. Без выбранной фигуры можно перетаскивать фигуры мышью.
5. Используйте `Ход белых` / `Ход чёрных`, чтобы указать сторону хода.
6. Кнопка `Импорт FEN` открывает ввод позиции. Нажмите `Enter`, чтобы применить FEN.
7. `Экспорт FEN` копирует позицию в буфер обмена и сохраняет её в `fen_export.txt`.

Перед переходом в режим игры редактор проверяет корректность позиции. Для полноценной партии на доске должны быть оба короля и соблюдены шахматные правила.

## Как работает анализ

Приложение запускает Stockfish в отдельном рабочем потоке. Это сохраняет отзывчивость интерфейса во время расчёта. Для выбранной позиции движок возвращает:

- оценку с точки зрения белых: `+0.32` означает преимущество белых, `-0.45` — преимущество чёрных;
- мат в формате `#N`;
- до трёх главных вариантов (principal variations);
- стрелку первого хода лучшего варианта на доске.

Устаревшие результаты не применяются: если положение изменилось во время анализа, результат для старой позиции игнорируется.

## Структура проекта

```text
.
├── app.py             # интерфейс, правила, редактор и работа с движком
├── ava.jpg            # значок окна и аватар разработчика
├── requirements.txt   # зависимости Python
├── run.bat            # запуск на Windows
└── stockfish/         # локальная сборка Stockfish
```

## Проверка установки

После запуска в верхней части панели должна появиться зелёная надпись `Stockfish готов`. Если вместо неё отображается ошибка, проверьте, что `stockfish/stockfish-windows-x86-64-avx2.exe` существует и может быть запущен на вашем компьютере.
